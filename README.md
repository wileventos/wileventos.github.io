# Agenda WIL EVENTOS

Página pública com as datas disponíveis do espaço WIL EVENTOS (Teresina-PI): https://wileventos.github.io

- `agenda.json` é atualizado automaticamente pelo sistema WIL EVENTOS e contém **somente** datas e situação (`reservado` ou `negociacao`). Nenhum dado de cliente é publicado aqui.
- O formulário não envia dados para este site: ele monta uma mensagem e abre o WhatsApp do WIL EVENTOS.
